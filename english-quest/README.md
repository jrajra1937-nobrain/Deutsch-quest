# English Quest

A2 から C1 までの英語を、**理解 → 4択演習 → 声に出す → 作文**の順で練習する静的Webアプリ。

**公開予定URL**: https://jrajra1937-nobrain.github.io/Deutsch-quest/english-quest/

## 収録教材
- CEFR A2 / B1 / B2 / C1：各6章、計24章
- 固定IDを持つ4択：各レベル56問、計224問（読解8題×4問を含む）
- Speaking：8課題/レベル、計32課題
- Writing：4課題/レベル、計16課題
- 日本語訳と、正解の理由
- 学習記録、XP、連続日数、復習抽出、JSONバックアップ

## 習得判定
各設問は独立した固定IDを持つ（例：`a2-01-q01`）。
正解でそのIDの連続正解数 `hits` を +1、2/2で習得。
不正解はそのIDだけ0に戻す。
同一テーマでも文章や単語が異なる設問は別IDとなり、習得が共有されない。
1回正解後は24時間、2回正解後は72時間を目安に復習対象となる。
セッション内では同じ設問を重複出題しない。

## 保存とプライバシー
すべてブラウザで動作し、ログイン・サーバー・APIキーは不要。
進捗、作文下書き、発話練習回数は端末の`localStorage`に保存される。
端末間で自動同期しない。別端末にはJSONバックアップを使う。
発音ボタンは録音済みMP3の再生に限定。MP3が未生成ならボタンは非表示、再生失敗したボタンも非表示。
音声ファイルはGitHub Actionsから生成し、音声とマニフェストを一括コミット。音声はファイルとして配信されるため、ブラウザのWeb Speech APIの読み上げ機能には依存しない。
マイクはブラウザの音声認識に対応した環境でのみ使用。認識精度・利用可否はブラウザ依存。
発話や作文は**自動的なCEFR評価を行わない**。4択だけで英会話力を証明するものではない。

## デプロイ
`english-quest/index.html`を静的ホスティングのサブパスで公開。
必要ファイル：`index.html`、`content.js`、`manifest.webmanifest`、`icon.svg`、`sw.js`。録音済み音声を提供するには追加で `audio-map.json` と `audio/**/*.mp3` が必要。
サービスワーカーのスコープは英語版のフォルダ内のみ。Deutsch Quest本体には触れない。
GitHub Pagesが`main`の`/(root)`を公開元としている場合、上記URLでアクセス可能。

## ローカル/ブラウザ検証
`tests.html`を同じフォルダから開くと、教材データの整合性テストが実行される。
初回はネット接続が必要。次回以降はService Workerのキャッシュでオフライン利用可能。

## この版の限界
教材は質と誤答解説に重点を置いた初期版。224問の選択問題だけでC1や「完璧に話せる」水準は保証されない。
実践会話と作文添削は、外部評価（教師、パートナーなど）と組み合わせることが推奨される。
